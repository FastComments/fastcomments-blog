# [postlink]FastComments עכשיו ב‑Zapier[/postlink]

{{#unless isPost}}
חברו את ההערות שלכם לאלפי אפליקציות עם האפליקציה הרשמית של FastComments ל‑Zapier. הטריגרים מתרחשים ברגע שהערה מתפרסמת, וכל אפליקציה יכולה ליצור הערות, דפים ומשתמשים באתר שלכם.
{{/unless}}

{{#isPost}}

### מה חדש

כעת קיימת אפליקציה רשמית של FastComments ב‑[Zapier](https://zapier.com). התחברו פעם אחת מהעורך של Zapier ותוכלו לשלוח כל תגובה חדשה ל‑Slack, לרשום אותה בגיליון אלקטרוני, להוסיף מגיבים ל‑CRM שלכם, או ליצור תגובות מהגשת טופס, ללא כתיבת קוד.

לפני זה, חיבור FastComments לכלי אחר דרש הקמת מקבל webhook משלכם או כתיבה נגד ה‑REST API. שני האפשרויות עדיין עובדות. אפליקציית Zapier מיועדת למקרים שבהם אתם מעדיפים לא להריץ דבר.

### טריגרים

שלושה טריגרים, כולם מיידיים:

- **New Comment** מתרחש כאשר תגובה מתפרסמת. כברירת מחדל רק תגובות מאושרות ולא ספאם מופעלות, כך ש‑Zap שמפרסם לערוץ ציבורי לא ידלוף פריטים שעדיין בתור המודרציה. יש תיבת סימון לכלול הכל.
- **Updated Comment** מתרחש כאשר תגובה נערכת, מאושרת, מקבלת הצבעה, מוצמדת, או משתנה באופן אחר. ניתן לסנן לפי שדה האישור והטריגר הופך ל‑“approved comment”.
- **Deleted Comment** מתרחש כאשר תגובה נמחקת, כולל כל תוכן התגובה לצרכי רישום.

לכל טריגר יש אפשרות לסינון לפי תחום, המפרט את התחומים שהוגדרו בחשבון שלכם, כך ש‑Zap יכול לעקוב אחרי אתר אחד מתוך רבים.

הטריגרים מבוססים על webhooks, ולא על polling. FastComments משדר את האירוע ל‑Zapier ברגע שהוא מתרחש, ואין שום תהליך שמבצע polling לחשבון שלכם בזמן ההמתנה, והמתנה אינה צורכת קרדיט API.

### פעולות וחיפושים

פעולות קוראות ל‑FastComments API בשמך:

- **Create Comment** על כל דף, כמגיב בעל שם או משתמש SSO קיים, באופן אופציונלי כתשובה.
- **Create Page**, כך שניתן לרשום דף ולהגביל אותו לקבוצות חברים לפני שהן מקבלות את ההערה הראשונה.
- **Create SSO User**, כך שחברים מכלים אחרים שלכם יכולים להגיב תחת זהותם.
- **Create Feed Post** ו‑**Create Hash Tag**.
- **Flag Comment** לסקירת מודרטור.

חיפושים מחפשים פריטים לשימוש בשלבים מאוחרים יותר: **Find Comment** לפי מזהה, **Find SSO User** לפי אימייל, ו‑**Find Page** לפי מזהה URL. צמדו חיפוש עם יצירה תואמת במצב “find or create” של Zapier והמשתמש או הדף החסרים ייווצרו עבורכם.

### כמה Zaps להתחלה

- New New Comment, ולאחר מכן Slack “Send Channel Message”. מפתחים את שם המגיב, את ההערה ואת כתובת ה‑URL של הדף. השתמשו בסינון התחום כדי לנתב כל אתר לערוץ שלו.
- New New Comment, ולאחר מכן Google Sheets “Create Spreadsheet Row”, כאשר Deleted Comment מוסיף שורה נוספת כ‑Zap שני. הגיליון הופך למסלול ביקורת.
- Updated Updated Comment עם סינון על Approved = true, ולאחר מכן Gmail “Send Email” כדי ליידע את המחבר שההערה שלו חיה.
- Typeform “New Response”, ולאחר מכן Create Comment בדף ההמלצות שלכם עם Approved לא מסומן, כך שתבצעו סקירה לפני שההערה תופיע.
- WordPress “New Post”, ולאחר מכן Create Page, כך שכל פוסט נרשם לפני ההערה הראשונה.

[המדריך](https://docs.fastcomments.com/guide-installation-zapier.html) כולל מידע נוסף, כולל זרימת עבודה לאספקת משתמשי SSO מכלי החברות שלכם.

### איך זה מתחבר

האפליקציה משתמשת ב‑OAuth. כאשר אתם מוסיפים שלב של FastComments, Zapier שואל את האזור שלכם (United States או EU), מעביר אתכם ל‑FastComments להתחבר, ומציג דף הסכמה שמציין את האפליקציה, החשבון שאליו היא תתחבר, וההרשאות המבוקשות. אין מפתח API שמועתק ל‑Zapier.

האדם המאשר את החיבור חייב להיות מנהל API בחשבון. לבעלי החשבון כבר יש הרשאה זו ויכולים להעניק אותה לחברי צוות אחרים בעמוד Users.

כל חיבור מופיע תחת **Integrate**, ואז **Connected Apps** בלוח הבקרה שלכם, מסומן כאינטגרציה רשמית, עם תאריך השימוש האחרון. ביטול החיבור שם מנתק את Zapier מיידית. הפעלת Zap יוצרת מנוי webhook שניתן לראות בעמוד Webhooks עם המקור **API**, וכיבוי ה‑Zap מסיר אותו.

### מה העלות

האפליקציה חינמית בכל תוכנית של Zapier, כולל החינמית, ו‑FastComments לא גובה תשלום נוסף עבורה. הטריגרים אינם צורכים קרדיט API. הפעולות והחיפושים צורכים את אותם קרדיטים שהייתם מוציאים בקריאה מקוד שלכם, אחד לכל קריאה ברוב המקרים.

### תיעוד

[המדריך ל‑Zapier](https://docs.fastcomments.com/guide-installation-zapier.html) מכסה חיבור חשבון, כל טריגר ופעולה עם השדות שלהם, דוגמאות Zaps, ופתרון בעיות. האינטגרציה עצמה היא קוד פתוח ב‑[github.com/FastComments/fastcomments-zapier](https://github.com/FastComments/fastcomments-zapier).
