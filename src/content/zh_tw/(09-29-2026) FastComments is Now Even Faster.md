# [postlink]FastComments 現在更快了[/postlink]

{{#unless isPost}}
我們已在載入評論小工具時移除了一個網路請求，進一步降低載入時間。
{{/unless}}

{{#isPost}}

### <i class="circle">!</i> 此文章包含技術術語

### 新功能

過去大約五年來，FastComments 的運作方式是先載入一段小腳本，接著載入 iframe，然後載入包含樣式的腳本，最後向 API 發出請求以取得繪製評論所需的所有資料。雖然聽起來步驟不少，但相較於大多數系統而言，這已相當精簡！

然而，現在甚至少了一個請求。傳送小工具的 iframe 回應同時攜帶了評論以及使用者最初所需的所有資料，因而最後的 API 請求已不再需要。

API 仍會維持，以確保相容舊版使用者的需求。

### 無需設定

此功能不需要任何設定，也沒有需要升級的版本。只要使用我們的腳本嵌入 FastComments，即已自動擁有此功能。

無論如何，您的頁面都不會受到影響。小工具仍會在 iframe 中載入，且不會阻塞您的內容，與之前完全相同。

### 不適用的情況

有少數情況不會使用此方式，且它們的行為與以往完全相同：

- 搜尋引擎爬蟲，已直接將評論渲染到頁面中，而非使用 iframe
- 使用者活動資訊流與標籤過濾，會從不同的端點讀取資料

### 結論

我們希望您持續享受使用我們的平台，並期盼我們的改進能為您帶來價值。 :)

敬上！
