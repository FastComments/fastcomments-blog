# [postlink]FastComments 預設頭像使用 Gravatar[/postlink]

### 什麼是頭像？

頭像是與每個帳戶相關聯的個人資料圖示，會顯示在每則評論旁邊。

### 什麼是 Gravatar？

<a href="https://gravatar.com/" target="_blank">Gravatar</a> 自稱「全球認可的頭像」服務。它是一項服務，讓您可以為特定電子郵件設定頭像。之後，使用該電子郵件註冊的任何產品都可以使用該頭像。這為註冊 FastComments 的使用者省去了一個步驟，因為他們的頭像會自動設定。

### 那麼變更是什麼？

FastComments 現在會從 Gravatar 取得預設頭像。您或使用者不需要做任何事即可使用此功能。

如果您現有的使用者已經自行設定了頭像——別擔心，我們不會覆寫他們的自訂頭像。此外，使用者仍然可以在 FastComments 中覆寫 Gravatar 頭像。
