# [postlink]Выполнены важные обновления безопасности[/postlink]

{{#unless isPost}}
Мы обновили операционную систему на всех наших серверах, чтобы исправить недавнюю уязвимость Linux TCP, и обновили Node.js, чтобы включить его октябрьский релиз безопасности. Действий с вашей стороны не требуется.

{{#isPost}}

### Что нового

Недавно мы завершили два обновления безопасности в инфраструктуре FastComments: обновление операционной системы для исправления уязвимости в TCP‑коде ядра Linux и обновление Node.js для включения последнего релиза безопасности.

### Ядро Linux

Все наши серверы были обновлены и теперь работают на ядре, включающем исправление для <a href="https://security-tracker.debian.org/tracker/CVE-2026-98432" target="_blank">CVE-2026-98432</a>.

Это уязвимость типа use-after-free в IPv4‑TCP‑коде ядра. Ядро могло освобождать IP‑опции, прикреплённые к соединению, пока другой процессор всё ещё читал их, например при построении ответа SYNACK во время TCP‑рукопожатия. Исправление ждёт, пока ни один процессор больше не читает эту память, прежде чем освободить её.

### Node.js

FastComments работает на Node.js, и мы обновились до версии 24.22.1, исправленного релиза для ветки 24.x из <a href="https://nodejs.org/en/blog/vulnerability/october-2026-security-releases" target="_blank">октябрьского релиза безопасности Node.js 2026</a>.

Этот релиз исправляет 10 уязвимостей в поддерживаемых версиях Node.js. 8 из них затрагивают ветку 24.x, и 4 из них имеют высокий уровень риска: две в проверке TLS IP‑адресов, одна в обработке DNS‑имен и одна в декодере Brotli. Он также обновляет включённые зависимости, включая OpenSSL, c-ares, Undici и набор сертификатов CA.

### Что вам нужно сделать

Ничего. Эти обновления выполнены полностью с нашей стороны, поэтому ваши виджеты, интеграции API и конфигурации SSO не требуют изменений.

### В заключение

Поддержание нашей инфраструктуры в актуальном состоянии — постоянная часть работы FastComments, и мы будем продолжать применять такие обновления по мере их выпуска. Если у вас есть вопросы, дайте нам знать ниже.

С уважением!
