# [postlink]FastComments теперь в Zapier[/postlink]

{{#unless isPost}}
Подключите свои комментарии к тысячам приложений с официальным приложением FastComments для Zapier. Триггеры срабатывают в момент публикации комментария, и любое приложение может создавать комментарии, страницы и пользователей на вашем сайте.
{{/unless}}

{{#isPost}}

### What's New

Теперь доступно официальное приложение FastComments на [Zapier](https://zapier.com). Войдите один раз из редактора Zapier, и вы сможете отправлять каждый новый комментарий в Slack, сохранять их в таблицу, добавлять комментаторов в вашу CRM или создавать комментарии из отправки формы, без написания кода.

До этого интеграция FastComments с другим инструментом означала создание собственного получателя вебхуков или написание кода против REST API. Оба варианта по‑прежнему работают. Приложение Zapier предназначено для случаев, когда вы предпочитаете ничего не запускать.

### Triggers

Three triggers, all instant:

- **New Comment** срабатывает, когда публикуется комментарий. По умолчанию триггером являются только одобренные, не являющиеся спамом комментарии, поэтому Zap, отправляющий сообщения в публичный канал, не раскрывает комментарии, находящиеся в очереди модерации. Есть флажок, позволяющий включить все.
- **Updated Comment** срабатывает, когда комментарий редактируется, одобряется, получает голос, закрепляется или иным образом изменяется. Фильтрация по полю approved превращает его в триггер «одобренный комментарий».
- **Deleted Comment** срабатывает, когда комментарий удаляется, предоставляя полный комментарий для ваших записей.

Каждый триггер имеет необязательный фильтр домена, перечисляющий домены, настроенные в вашей учетной записи, поэтому Zap может отслеживать один сайт из множества.

Триггеры реализованы через вебхуки, а не опрос. FastComments отправляет событие в Zapier в момент его возникновения, ничего не опрашивает вашу учетную запись в ожидании, и ожидание не стоит API‑кредитов.

### Actions and Searches

Действия вызывают API FastComments от вашего имени:

- **Create Comment** на любой странице, от имени именованного комментатора или существующего SSO‑пользователя, при желании в виде ответа.
- **Create Page**, чтобы страницу можно было добавить в список и ограничить доступ группами участников до появления первого комментария.
- **Create SSO User**, чтобы участники из ваших других инструментов могли комментировать под своей личностью.
- **Create Feed Post** и **Create Hash Tag**.
- **Flag Comment** для проверки модератором.

Поиски позволяют находить данные для последующих шагов: **Find Comment** по id, **Find SSO User** по email и **Find Page** по URL‑ID. Сочетайте поиск с соответствующим созданием в режиме Zapier «find or create», и недостающий пользователь или страница будет создана автоматически.

### A Few Zaps to Start With

- New Comment, затем Slack «Send Channel Message». Сопоставьте имя комментатора, текст комментария и URL страницы. Используйте фильтр домена, чтобы направлять каждый сайт в свой канал.
- New Comment, затем Google Sheets «Create Spreadsheet Row», при этом Deleted Comment добавляет строку как второй Zap. Таблица становится журналом аудита.
- Updated Comment, отфильтрованный по Approved = true, затем Gmail «Send Email», чтобы уведомить автора, что его комментарий опубликован.
- Typeform «New Response», затем Create Comment на странице отзывов с отключённым флажком Approved, чтобы вы могли проверять каждый комментарий перед публикацией.
- WordPress «New Post», затем Create Page, чтобы каждый пост был зарегистрирован до появления первого комментария.

[The guide](https://docs.fastcomments.com/guide-installation-zapier.html) содержит больше информации, включая рабочий процесс создания SSO‑пользователей из вашего инструмента управления членством.

### How It Connects

Приложение использует OAuth. Когда вы добавляете шаг FastComments, Zapier запрашивает ваш регион (United States или EU), перенаправляет вас на FastComments для входа и отображает страницу согласия, указывающую приложение, учетную запись, к которой будет выполнено подключение, и запрашиваемые разрешения. Ключ API не копируется в Zapier.

Лицо, одобряющее подключение, должно быть администратором API в учетной записи. Владельцы аккаунтов уже имеют такие права и могут предоставить их другим членам команды на странице Users.

Каждое подключение отображается в разделе **Integrate**, затем **Connected Apps** в вашей панели управления, помечено как официальная интеграция с указанием времени последнего использования. Отзыв подключения там немедленно отключает Zapier. Включение Zap создает подписку на вебхук, которую можно увидеть на странице Webhooks с источником **API**, а отключение Zap удаляет её.

### What It Costs

Приложение бесплатно на любом тарифе Zapier, включая бесплатный, и FastComments не взимает за него дополнительную плату. Триггеры не расходуют API‑кредиты. Действия и поиски тратят те же кредиты, что и вызов из вашего собственного кода, обычно один кредит за вызов.
