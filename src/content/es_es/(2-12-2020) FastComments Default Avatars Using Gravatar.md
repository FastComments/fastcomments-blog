# [postlink]Avatares Predeterminados de FastComments Usando Gravatar[/postlink]

### ¿Qué es un Avatar?

Un avatar es el ícono de perfil asociado a cada cuenta y se muestra junto a cada comentario.

### ¿Qué es Gravatar?

<a href="https://gravatar.com/" target="_blank">Gravatar</a> se presenta a sí mismo como "A Globally Recognized Avatar". Es un servicio donde puedes definir un avatar para un correo electrónico dado. Cualquier producto al que te registres usando ese correo puede entonces usar ese avatar. Esto elimina un paso para las personas que se registran en FastComments ya que su avatar se configura automáticamente.

### ¿Entonces cuál es el cambio?

FastComments ahora obtendrá los avatares predeterminados de Gravatar. Tú o los usuarios no tienen que hacer nada para obtener esta función.

Si tus usuarios existentes ya han definido su propio avatar, no te preocupes, no vamos a sobrescribir sus avatares personalizados. Además, los usuarios aún pueden sobrescribir el avatar de Gravatar en FastComments.
