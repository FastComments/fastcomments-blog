# [postlink]Προσθέστε Ζωντανές Ψηφοφορίες στα Σχόλια Σας με το FastComments[/postlink]

{{#unless isPost}}
Τα σχόλια έχουν τώρα ζωντανές ψηφοφορίες! Οι αναγνώστες ψηφίζουν μέσα στο νήμα, τα αποτελέσματα ενημερώνονται ζωντανά για όλους στη σελίδα, και οι ψηφοφορίες λειτουργούν σε όλο το web widget και στα iOS, Android και React Native SDK μας.
{{/unless}}

{{#isPost}}

### Τι Νέο

Αυτή η έκδοση προσθέτει **Live Polls**. Μια ψηφοφορία συνδέεται με ένα σχόλιο και εμφανίζεται μέσα σε αυτό. Οι αναγνώστες κάνουν κλικ σε μια επιλογή για να ψηφίσουν, χωρίς να αφήσουν το νήμα, και τα αποτελέσματα ενημερώνονται ζωντανά για όλους που βλέπουν τη σελίδα καθώς έρχονται οι ψήφοι. Χωρίς ανανέωση, και κανείς δεν χρειάζεται να μετράει τις απαντήσεις με το χέρι.

<img src="images/fc-live-polls.png" alt="A comment with a poll asking what format the next meetup should be, showing In person at 34%, Online at 21%, and Hybrid at 45%, with 53 responses" title="Live Polls" class="lozad" />

Επειδή η ψηφοφορία είναι ένα σχόλιο, η συζήτηση παραμένει συνδεδεμένη με αυτό. Οι άνθρωποι ψηφίζουν, και μετά απαντούν για να εξηγήσουν γιατί.

### Δημιουργία Ψηφοφορίας

Όταν οι ψηφοφορίες είναι ενεργές, ο επεξεργαστής σχολίων εμφανίζει ένα κουμπί ψηφοφορίας. Κάνοντας κλικ σε αυτό ανοίγει έναν επεξεργαστή ψηφοφορίας κάτω από το πεδίο κειμένου, όπου μπορείτε να ορίσετε:

- **Η ερώτηση**, έως 200 χαρακτήρες.
- **Οι επιλογές**, 2 έως 10.
- **Πότε κλείνει**: ποτέ, ή μετά από 1 ημέρα, 3 ημέρες ή 1 εβδομάδα. Μια κλειστή ψηφοφορία δείχνει τα τελικά της αποτελέσματα και σταματά να δέχεται ψήφους.
- **Απόρρητο**: ανώνυμη, ορατή στους διαχειριστές, ή δημόσια.
- **Απαιτείται Ψήφος για να Δείτε τα Αποτελέσματα**, που κρατά τα αποτελέσματα κρυμμένα από κάθε θεατή μέχρι να ψηφίσει ή μέχρι να κλείσει η ψηφοφορία.

Στη συνέχεια γράψτε το σχόλιό σας και δημοσιεύστε το όπως συνήθως. Οι ψηφοφορίες λειτουργούν σε νέα σχόλια και σε απαντήσεις.

### Ψηφοφορία

Κάθε άτομο παίρνει μία ψήφο ανά ψηφοφορία, και μπορεί να την αλλάξει ενώ η ψηφοφορία είναι ανοιχτή. Εκτός εάν η ψηφοφορία απαιτεί ψήφο πρώτα, οι αναγνώστες μπορούν να κάνουν κλικ στο **Εμφάνιση αποτελεσμάτων** για να δουν την κατάσταση πριν επιλέξουν.

Το απόρρητο ορίζεται ανά ψηφοφορία και εμφανίζεται ακριβώς κάτω από τις επιλογές, ώστε οι ψηφοφόροι να γνωρίζουν ποιος μπορεί να δει την ψήφο τους πριν την καταθέσουν. Οι ανώνυμες ψηφοφορίες (η προεπιλογή) δείχνουν μόνο τα σύνολα, και κανείς, συμπεριλαμβανομένων των διαχειριστών, δεν μπορεί να δει ποιος ψήφισε τι. Σε ψηφοφορίες ορατές στους διαχειριστές, οι διαχειριστές και οι συντονιστές μπορούν να ανοίξουν **Δείτε ποιος ψήφισε**. Σε δημόσιες ψηφοφορίες, μπορεί οποιοσδήποτε.

### Ενεργοποίηση

Οι ψηφοφορίες είναι απενεργοποιημένες από προεπιλογή. Ανοίξτε το <a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">Widget Customization</a>, τσεκάρετε **Enable Polls**, και επιλέξτε ποιος μπορεί να τις δημιουργήσει:

- **Admins/Moderators Only** (η προεπιλογή), όταν θέλετε να διαχειρίζεστε τις ψηφοφορίες μόνοι σας.
- **Everyone**, όταν θέλετε η κοινότητά σας να ρωτάει η μία την άλλη.

Η ψήφωση απαιτεί προεπιλογή έναν συνδεδεμένο χρήστη. Ενεργοποιήστε **Allow Anonymous Poll Votes** για να επιτρέψετε σε οποιονδήποτε να ψηφίσει. Για να είναι δίκαιο, οι ανώνυμες ψήφοι περιορίζονται σε τρεις ανά διεύθυνση IP ανά ψηφοφορία ανά ώρα.

Όπως κάθε κανόνας προσαρμογής, αυτό μπορεί να ισχύει για ολόκληρο τον ιστότοπό σας, ένα domain ή μια μεμονωμένη σελίδα.

### Ειδοποιήσεις

Ο δημιουργός μιας ψηφοφορίας λαμβάνει πληροφορίες για τις απαντήσεις καθώς έρχονται: μια ειδοποίηση, ομαδοποιημένη όταν πολλοί άνθρωποι ψηφίζουν ταυτόχρονα, και ένα καθημερινό email όταν η ψηφοφορία έλαβε νέες απαντήσεις εκείνη τη μέρα. Μόνο η πρώτη ψήφος μετράει ως απάντηση, έτσι ώστε κάποιος που αλλάζει γνώμη να μην στέλνει περισσότερα. Οι ειδοποιήσεις ακολουθούν το απόρρητο της ψηφοφορίας, έτσι μια ανώνυμη ψηφοφορία αναφέρει μόνο πόσες νέες απαντήσεις έφτασαν, ποτέ ποιος.

### Native Mobile SDKs

Οι ψηφοφορίες δεν είναι μόνο στο web widget. Τα native SDK μας αποδίδουν την κάρτα ψηφοφορίας, τον επεξεργαστή ψηφοφορίας, τα ζωντανά αποτελέσματα και τη λίστα ψηφοφόρων με πραγματικά native components, και διαβάζουν τις ίδιες ρυθμίσεις widget από τον πίνακά σας. Ενεργοποιήστε τις ψηφοφορίες μία φορά και θα εμφανιστούν στον ιστότοπό σας και στις εφαρμογές σας.

- **iOS**: <a href="https://github.com/FastComments/fastcomments-ios" target="_blank">fastcomments-ios</a> 2.1.0, μέσω Swift Package Manager.
- **Android**: <a href="https://github.com/FastComments/fastcomments-android" target="_blank">fastcomments-android</a> 2.1.0, ως `com.fastcomments:android-sdk:2.1.0`.
- **React Native**: <a href="https://www.npmjs.com/package/fastcomments-react-native-sdk" target="_blank">fastcomments-react-native-sdk</a> 5.3.0, στο NPM.

Τα iOS και Android SDK μπορούν επίσης να δημοσιεύσουν μια ψηφοφορία από το δικό σας UI. Στο iOS φαίνεται έτσι:

    try await sdk.postComment(text: "Lunch vote", poll: draft.toInput())
}</div>

### Το API

Οι ψηφοφορίες είναι επίσης στο REST API. Μπορείτε να δημιουργήσετε μια ψηφοφορία μαζί με το σχόλιό της περνώντας `poll` στο `POST /api/v1/comments`, ή να προσθέσετε, επεξεργαστείτε, κλείσετε και αφαιρέσετε μια αργότερα με `/api/v1/polls/:commentId`. Οι ψήφοι μπορούν να ληφθούν, να κατατεθούν και να αφαιρεθούν με `/api/v1/poll-votes`, κάτι που καθιστά την εξαγωγή των αποτελεσμάτων σε υπολογιστικό φύλλο ή το δικό σας CMS απλή διαδικασία. Το API ακολουθεί τις ίδιες ρυθμίσεις με το widget, και οι μεμονωμένες ψήφοι σε ανώνυμες ψηφοφορίες δεν μπορούν να διαβαστούν μέσω αυτού.

### Πρόσθετο Φόρτο

Ο κώδικας της ψηφοφορίας δεν φορτώνεται εκτός εάν οι ψηφοφορίες είναι ενεργοποιημένες, έτσι δεν επιβραδύνει το widget σχολίων για κανέναν άλλον.

### Τεκμηρίωση

<a href="https://docs.fastcomments.com/guide-polls.html" target="_blank">Ο οδηγός Live Polls</a> καλύπτει την ενεργοποίηση των ψηφοφοριών, ποιος μπορεί να τις δημιουργήσει, τις ανώνυμες ψήφους, το απόρρητο των ψηφοφόρων, τις ειδοποιήσεις και το API.

### Δοκιμάστε το

Υπάρχει μια ζωντανή ψηφοφορία στο <a href="https://fastcomments.com/product/live-polls" target="_blank">Live Polls demo</a>. Ψηφίστε, ανοίξτε τη σελίδα σε δεύτερη καρτέλα και παρακολουθήστε τα αποτελέσματα να κινούνται. Μπορείτε επίσης να δημοσιεύσετε τη δική σας ψηφοφορία εκεί.

### Συμπερασματικά

Αν τα νήματά σας μετατρέπονται συνεχώς σε καταμετρήσεις, δοκιμάστε τις ψηφοφορίες και ενημερώστε μας παρακάτω τι θα θέλατε να δείτε στη συνέχεια.
