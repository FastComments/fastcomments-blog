# [postlink]Προπληρώστε το Τιμολόγιό σας με Αναπληρώσεις Πίστωση[/postlink]

{{#unless isPost}}
Μπορείτε τώρα να προσθέσετε πίστωση στον λογαριασμό σας FastComments από τη σελίδα τιμολόγησης. Η πίστωση εφαρμόζεται στα μελλοντικά σας τιμολόγια, συμπεριλαμβανομένων των ανανεώσεων και της χρήσης Flex, πριν χρεωθεί η κάρτα σας.
{{/unless}}

{{#isPost}}

### Τι Νέο

Μέχρι τώρα υπήρχε ένας μόνο τρόπος πληρωμής για το FastComments: χρεώναμε την κάρτα σας όταν ένα τιμολόγιο έφτανε στην ημερομηνία λήξης. Αυτό είναι εντάξει για τους περισσότερους λογαριασμούς, αλλά όχι για όλους. Ορισμένα τμήματα οικονομικών προτιμούν να κάνουν μία πληρωμή και να είναι εντάξει για κάποιο χρονικό διάστημα. Ορισμένοι πελάτες Flex προτιμούν να πληρώνουν για έναν πολυάσχολο μήνα εκ των προτέρων παρά να εκπλαγούν.

Τώρα μπορείτε να τοποθετήσετε χρήματα στον λογαριασμό. Η σελίδα τιμολόγησης έχει ένα νέο κουμπί **Manage Credits**, δίπλα στα **View Invoices** και **Invoice Settings**. Ανοίγει μια σελίδα **Credits** όπου μπορείτε να δείτε το υπόλοιπό σας και να το αυξήσετε.

Η πίστωση είναι χρήματα που κρατούνται στον λογαριασμό σας FastComments, στο νόμισμα τιμολόγησής σας. Όταν δημιουργείται ένα τιμολόγιο, η πίστωση εφαρμόζεται πρώτα, και μόνο το υπόλοιπο, εάν υπάρχει, χρεώνεται στην κάρτα σας. Αυτό καλύπτει τις ανανεώσεις συνδρομής, τις χρεώσεις χρήσης Flex και οτιδήποτε άλλο σας τιμολογούμε. Δεν υπάρχει κάτι να ρυθμίσετε ή να θυμάστε· μόλις το υπόλοιπο είναι εκεί, χρησιμοποιείται.

### Προσθήκη Πίστωσης

1. Ανοίξτε <a href="https://fastcomments.com/auth/my-account/billing-info" target="_blank">My Account -> Billing Info</a> και κάντε κλικ στο **Manage Credits**.
2. Στην ενότητα **Add credit**, επιλέξτε ένα από τα προκαθορισμένα ποσά (10, 25, 50 ή 100 στο νόμισμά σας) ή επιλέξτε **Other amount** και πληκτρολογήστε το δικό σας, οπουδήποτε από 5 έως 10.000 ανά αναπλήρωση.
3. Κάντε κλικ στο **Add**. Η αποθηκευμένη κάρτα σας χρεώνεται, και αν η τράπεζά σας ζητήσει επιβεβαίωση της πληρωμής, αυτό συμβαίνει εκεί.
4. Η σελίδα εμφανίζει **Credit added** με το νέο σας υπόλοιπο.

Κάθε αναπλήρωση εμφανίζεται στον πίνακα **Past top-ups** στην ίδια σελίδα, με την ημερομηνία, το ποσό και αν ήταν **Credited**, **Pending** ή **Failed**. Αν μια κάρτα απορριφθεί, δεν χρεώνεται τίποτα και το υπόλοιπο δεν αλλάζει.

Μόνο ο κάτοχος του λογαριασμού ή ένας χρήστης με την άδεια **Billing Admin** μπορεί να προσθέσει πίστωση, οι ίδιοι που μπορούν να αλλάξουν το πλάνο ή τη μέθοδο πληρωμής σήμερα.

### Οι Λεπτομέρειες

Η πίστωση δεν είναι έκπτωση, σύστημα πόντων ή ξεχωριστό νόμισμα. Είναι τα δικά σας χρήματα, στο νόμισμά σας, που βρίσκονται στον λογαριασμό σας μέχρι να τα χρησιμοποιήσει ένα τιμολόγιο. Το υπόλοιπο εμφανίζεται στη σελίδα τιμολόγησης όποτε είναι πάνω από μηδέν, και κάθε τιμολόγιο δείχνει την πίστωση που εφαρμόστηκε.

Οι αναπληρώσεις χρησιμοποιούν τη μέθοδο πληρωμής που είναι ήδη αποθηκευμένη στον λογαριασμό σας, οπότε δεν υπάρχει δεύτερη διαδικασία αγοράς για να ρυθμίσετε. Αν δεν έχετε αποθηκεύσει κάρτα ακόμη, η σελίδα Credits σας οδηγεί στη σελίδα τιμολόγησης για να προσθέσετε μία πρώτα.

Οι λογαριασμοί που τιμολογούνται μέσω Shopify ή BigCommerce, καθώς και οι λογαριασμοί που τιμολογούνται εκτός του πίνακα ελέγχου, πληρώνονται σε αυτές τις πλατφόρμες, επομένως δεν θα δουν το κουμπί **Manage Credits**.

### Τεκμηρίωση

<a href="https://docs.fastcomments.com/guide-billing.html#credits" target="_blank">Ο νέος οδηγός Billing</a> καλύπτει πλήρως τις πιστώσεις: ποιος μπορεί να τις προσθέσει, τα όρια, πώς εφαρμόζονται, η επιβεβαίωση της τράπεζας, οι απορριπτέες κάρτες και ο πίνακας Past top-ups.

### Συμπερασματικά

Αν θέλετε να προπληρώσετε, να διατηρήσετε ένα αποθεματικό ενάντια στις χρεώσεις χρήσης, ή να κάνετε τον μήνα του λογιστικού τμήματος σας πιο εύκολο, αυτό είναι για εσάς. Ενημερώστε μας παρακάτω πώς λειτουργεί για εσάς και τι άλλο θα έκανε τη διαδικασία τιμολόγησης πιο απλή.

Στην υγειά σας!
