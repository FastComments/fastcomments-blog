# [postlink]FastComments Προεπιλεγμένα Avatar Χρησιμοποιώντας Gravatar[/postlink]

### Τι είναι ένα Avatar;

Ένα avatar είναι το εικονίδιο προφίλ που συνδέεται με κάθε λογαριασμό και εμφανίζεται δίπλα σε κάθε σχόλιο.

### Τι είναι το Gravatar;

<a href="https://gravatar.com/" target="_blank">Gravatar</a> προωθεί τον εαυτό του ως «A Globally Recognized Avatar». Είναι μια υπηρεσία όπου μπορείτε να ορίσετε ένα avatar για ένα συγκεκριμένο email. Οποιοδήποτε προϊόν εγγραφείτε χρησιμοποιώντας αυτό το email μπορεί στη συνέχεια να χρησιμοποιήσει εκείνο το avatar. Αυτό αφαιρεί ένα βήμα για τους ανθρώπους που εγγράφονται στο FastComments, καθώς το avatar τους ρυθμίζεται αυτόματα.

### Τι αλλαγή υπάρχει;

Το FastComments θα αντλεί πλέον προεπιλεγμένα avatar από το Gravatar. Εσείς ή οι χρήστες δεν χρειάζεται να κάνετε κάτι για να αποκτήσετε αυτή τη δυνατότητα.

Αν οι υπάρχοντες χρήστες σας έχουν ήδη ορίσει το δικό τους avatar - μην ανησυχείτε - δεν θα αντικαταστήσουμε τα προσαρμοσμένα avatar τους. Επίσης, οι χρήστες μπορούν ακόμη να αντικαταστήσουν το avatar του Gravatar στο FastComments.
