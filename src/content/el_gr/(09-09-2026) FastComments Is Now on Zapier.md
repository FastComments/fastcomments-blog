# [postlink]FastComments είναι τώρα στο Zapier[/postlink]

{{#unless isPost}}
Συνδέστε τα σχόλιά σας με χιλιάδες εφαρμογές μέσω της επίσημης εφαρμογής FastComments για Zapier. Οι ενεργοποιητές (triggers) εκτελούνται τη στιγμή που δημοσιεύεται ένα σχόλιο, και οποιαδήποτε εφαρμογή μπορεί να δημιουργήσει σχόλια, σελίδες και χρήστες στον ιστότοπό σας.

{{#isPost}}

### Τι νέο υπάρχει

Τώρα υπάρχει μια επίσημη εφαρμογή FastComments στο [Zapier](https://zapier.com). Συνδεθείτε μία φορά από τον επεξεργαστή του Zapier και μπορείτε να στέλνετε κάθε νέο σχόλιο στο Slack, να τα καταγράφετε σε ένα υπολογιστικό φύλλο, να προσθέτετε σχολιαστές στο CRM σας ή να δημιουργείτε σχόλια από υποβολή φόρμας, χωρίς να γράψετε κώδικα.

Πριν από αυτό, η ενσωμάτωση του FastComments σε άλλο εργαλείο σήμαινε την ανάγκη να στήσετε έναν δικό σας δέκτη webhook ή να γράψετε ενάντια στο REST API. Και τα δύο εξακολουθούν να λειτουργούν. Η εφαρμογή Zapier προορίζεται για τις περιπτώσεις όπου προτιμάτε να μην τρέχετε τίποτα.

### Ενεργοποιητές (Triggers)

Τρία ενεργοποιητές, όλοι άμεσοι:

- **New Comment** ενεργοποιείται όταν δημοσιεύεται ένα σχόλιο. Από προεπιλογή ενεργοποιούνται μόνο εγκεκριμένα, μη‑spam σχόλια, ώστε ένα Zap που στέλνει σε δημόσιο κανάλι να μην διαρρέει στοιχεία που βρίσκονται ακόμη στην ουρά ελέγχου. Υπάρχει ένα πλαίσιο ελέγχου για να συμπεριληφθούν όλα.
- **Updated Comment** ενεργοποιείται όταν ένα σχόλιο επεξεργάζεται, εγκρίνεται, ψηφίζεται, καρφιτσωθεί ή αλλιώς αλλάξει. Φιλτράρετε το πεδίο approved και γίνεται ενεργοποιητής «εγκεκριμένου σχολίου».
- **Deleted Comment** ενεργοποιείται όταν ένα σχόλιο διαγράφεται, με το πλήρες σχόλιο για τα αρχεία σας.

Κάθε ενεργοποιητής έχει ένα προαιρετικό φίλτρο domain που εμφανίζει τα domains που έχουν ρυθμιστεί στον λογαριασμό σας, ώστε ένα Zap να μπορεί να παρακολουθεί έναν ιστότοπο από πολλούς.

Οι ενεργοποιητές υποστηρίζονται από webhooks, όχι polling. Το FastComments παραδίδει το γεγονός στο Zapier τη στιγμή που συμβαίνει, τίποτα δεν ελέγχει (polls) τον λογαριασμό σας ενώ περιμένει, και η αναμονή δεν κοστίζει API credits.

### Ενέργειες και Αναζητήσεις

Οι ενέργειες καλούν το FastComments API εκ μέρους σας:

- **Create Comment** σε οποιαδήποτε σελίδα, ως ονομαστικός σχολιαστής ή υπάρχων χρήστης SSO, προαιρετικά ως απάντηση.
- **Create Page**, ώστε μια σελίδα να μπορεί να καταγραφεί και να περιοριστεί σε ομάδες μελών πριν το πρώτο της σχόλιο.
- **Create SSO User**, ώστε μέλη από άλλα εργαλεία σας να μπορούν να σχολιάζουν με τη δική τους ταυτότητα.
- **Create Feed Post** και **Create Hash Tag**.
- **Flag Comment** για έλεγχο από συντονιστή.

Οι αναζητήσεις εντοπίζουν στοιχεία για επόμενα βήματα: **Find Comment** με βάση το id, **Find SSO User** με βάση το email, και **Find Page** με βάση το URL ID. Συνδυάστε μια αναζήτηση με τη δημιουργία στην κατάσταση «find or create» του Zapier και ο ελλιπής χρήστης ή η σελίδα θα δημιουργηθούν για εσάς.

### Μερικά Zaps για Έναρξη

- New Comment, έπειτα Slack "Send Channel Message". Χαρτογραφήστε το όνομα του σχολιαστή, το σχόλιο και το URL της σελίδας. Χρησιμοποιήστε το φίλτρο domain για να δρομολογήσετε κάθε ιστότοπο στο δικό του κανάλι.
- New Comment, έπειτα Google Sheets "Create Spreadsheet Row", με Deleted Comment να προσθέτει μια γραμμή ως δεύτερο Zap. Το φύλλο γίνεται αρχείο ελέγχου.
- Updated Comment φιλτραρισμένο όπου Approved είναι true, έπειτα Gmail "Send Email" για να ενημερώσετε τον συγγραφέα ότι το σχόλιό του είναι ζωντανό.
- Typeform "New Response", έπειτα Create Comment στη σελίδα μαρτυριών σας με Approved μη επιλεγμένο, ώστε να ελέγχετε κάθε ένα πριν εμφανιστεί.
- WordPress "New Post", έπειτα Create Page, ώστε κάθε ανάρτηση να καταγραφεί πριν το πρώτο σχόλιο.

[Ο οδηγός](https://docs.fastcomments.com/guide-installation-zapier.html) περιέχει περισσότερα, συμπεριλαμβανομένου ενός workflow για την παροχή χρηστών SSO από το εργαλείο μέλους σας.

### Πώς Συνδέεται

Η εφαρμογή χρησιμοποιεί OAuth. Όταν προσθέτετε ένα βήμα FastComments, το Zapier ζητά την περιοχή σας (United States ή EU), σας στέλνει στο FastComments για σύνδεση και εμφανίζει μια σελίδα συναίνεσης που ονομάζει την εφαρμογή, τον λογαριασμό που θα συνδεθεί και τα ζητούμενα δικαιώματα. Δεν αντιγράφεται κανένα API key στο Zapier.

Το άτομο που εγκρίνει τη σύνδεση πρέπει να είναι API admin στον λογαριασμό. Οι ιδιοκτήτες λογαριασμού το έχουν ήδη και μπορούν να το χορηγήσουν σε άλλα μέλη της ομάδας στη σελίδα Users.

Κάθε σύνδεση εμφανίζεται κάτω από **Integrate, then Connected Apps** στον πίνακά σας, σημειωμένη ως επίσημη ενσωμάτωση, με την ημερομηνία τελευταίας χρήσης. Η ανάκληση εκεί διακόπτει αμέσως το Zapier. Η ενεργοποίηση ενός Zap δημιουργεί μια συνδρομή webhook που μπορείτε να δείτε στη σελίδα Webhooks με πηγή **API**, και η απενεργοποίηση του Zap την αφαιρεί.

### Πόσο Κοστίζει

Η εφαρμογή είναι δωρεάν σε κάθε πρόγραμμα του Zapier, συμπεριλαμβανομένου του δωρεάν, και το FastComments δεν χρεώνει επιπλέον. Οι ενεργοποιητές δεν καταναλώνουν API credits. Οι ενέργειες και οι αναζητήσεις καταναλώνουν τα ίδια credits όπως μια κλήση από τον δικό σας κώδικα, μία ανά κλήση στις περισσότερες περιπτώσεις.

### Τεκμηρίωση

[Ο οδηγός Zapier](https://docs.fastcomments.com/guide-installation-zapier.html) καλύπτει τη σύνδεση λογαριασμού, κάθε ενεργοποιητή και ενέργεια με τα πεδία τους, παραδείγματα Zaps και αντιμετώπίση προβλημάτων. Η ενσωμάτωση είναι ανοιχτού κώδικα στο [github.com/FastComments/fastcomments-zapier](https://github.com/FastComments/fastcomments-zapier).

Όπως πάντα, ενημερώστε μας παρακάτω αν αντιμετωπίσετε κάτι.
