### Τι Νέο

Πρόσφατα ολοκληρώσαμε δύο ενημερώσεις ασφαλείας στην υποδομή του FastComments: μια ενημέρωση του λειτουργικού συστήματος για να διορθώσουμε μια ευπάθεια στον κώδικα TCP του πυρήνα Linux, και μια ενημέρωση του Node.js για να ενσωματώσουμε την πιο πρόσφατη έκδοση ασφαλείας.

### Πυρήνας Linux

Όλοι οι διακομιστές μας έχουν ενημερωθεί και τώρα τρέχουν έναν πυρήνα που περιλαμβάνει τη διόρθωση για <a href="https://security-tracker.debian.org/tracker/CVE-2026-98432" target="_blank">CVE-2026-98432</a>.

Αυτή είναι μια ευπάθεια τύπου use-after-free στον κώδικα IPv4 TCP του πυρήνα. Ο πυρήνας θα μπορούσε να ελευθερώσει τις επιλογές IP που είναι συνδεδεμένες με μια σύνδεση ενώ ένας άλλος επεξεργαστής τα διάβαζε ακόμη, για παράδειγμα κατά τη δημιουργία της απάντησης SYNACK κατά τη διάρκεια μιας χειραψίας TCP. Η διόρθωση περιμένει μέχρι κανένας επεξεργαστής να μην διαβάζει πλέον αυτή τη μνήμη πριν την ελευθερώσει.

### Node.js

Το FastComments λειτουργεί σε Node.js, και έχουμε ενημερωθεί στην έκδοση 24.22.1, την διορθωμένη έκδοση για τη σειρά 24.x από την <a href="https://nodejs.org/en/blog/vulnerability/october-2026-security-releases" target="_blank">οκτωβριανή έκδοση ασφαλείας του Node.js 2026</a>.

Αυτή η έκδοση διορθώνει 10 ευπάθειες στις υποστηριζόμενες εκδόσεις του Node.js. 8 από αυτές επηρεάζουν τη σειρά 24.x, και 4 από αυτές αξιολογούνται ως υψηλές: δύο στην επικύρωση TLS των διευθύνσεων IP, μία στη διαχείριση ονομάτων DNS, και μία στον αποκωδικοποιητή Brotli. Επίσης ενημερώνει τις ενσωματωμένες εξαρτήσεις, συμπεριλαμβανομένων των OpenSSL, c-ares, Undici και του πακέτου πιστοποιητικών CA.

### Τι Πρέπει Να Κάνετε

Τίποτα. Αυτές οι ενημερώσεις είναι εξ ολοκλήρου από τη δική μας πλευρά, έτσι τα widgets, οι ενσωματώσεις API και οι ρυθμίσεις SSO σας δεν απαιτούν καμία αλλαγή.

### Συμπερασματικά

Η διατήρηση της υποδομής μας ενημερωμένης είναι ένα συνεχές μέρος της λειτουργίας του FastComments, και θα συνεχίσουμε να εφαρμόζουμε ενημερώσεις όπως αυτές μόλις κυκλοφορήσουν. Εάν έχετε οποιεσδήποτε ερωτήσεις, ενημερώστε μας παρακάτω.

Στην υγειά σας!
