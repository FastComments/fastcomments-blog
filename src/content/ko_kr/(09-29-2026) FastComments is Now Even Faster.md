# [postlink]FastComments가 이제 더 빨라졌습니다[/postlink]

{{#unless isPost}}
우리는 댓글 위젯을 로드할 때 네트워크 요청을 하나 제거하여 로드 시간을 더욱 단축했습니다.
{{/unless}}

{{#isPost}}

### <i class="circle">!</i> 이 문서는 기술 용어를 포함하고 있습니다

### 새로운 소식

FastComments가 지난 5년 정도 작동해 온 방식은 작은 스크립트를 로드하고, iframe이 로드된 다음 스타일을 포함하는 스크립트를 로드하고, 마지막으로 댓글을 그리는 데 필요한 모든 것을 API에 요청하는 것입니다. 많이 복잡해 보이지만 대부분의 시스템에 비해 매우 컴팩트합니다!

하지만 이제는 요청이 하나 더 줄어들었습니다. 위젯을 전달하는 iframe 응답에 댓글과 사용자가 처음에 필요로 하는 모든 데이터가 포함되므로 마지막 API 요청이 사라졌습니다.

API는 여전히 의존하는 사람들을 위해 하위 호환성을 유지합니다.

### 설정할 것이 없습니다

이를 위한 설정이나 업그레이드할 버전이 없습니다. FastComments를 우리 스크립트로 삽입하면 이미 적용됩니다.

귀하의 페이지는 어떤 경우에도 영향을 받지 않습니다. 위젯은 여전히 iframe으로 로드되며, 이전과 마찬가지로 콘텐츠를 차단하지 않습니다.

### 적용되지 않는 경우

몇몇 경로는 이를 사용하지 않으며, 항상 그랬던 대로 동작합니다:

- 검색 엔진 크롤러는 이미 댓글을 iframe이 아닌 페이지에 직접 렌더링합니다
- 사용자 활동 피드와 해시태그 필터링은 다른 엔드포인트에서 읽습니다

### 결론

우리 플랫폼을 계속 즐겨 사용하시길 바라며, 우리가 만든 개선 사항이 가치를 더하길 바랍니다. :)

감사합니다!
