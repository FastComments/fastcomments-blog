# [postlink]FastComments 기본 아바타를 Gravatar 사용[/postlink]

### 아바타란?

아바타는 모든 계정에 연결된 프로필 아이콘이며, 각 댓글 옆에 표시됩니다.

### Gravatar란?

<a href="https://gravatar.com/" target="_blank">Gravatar</a>는 스스로를 "전 세계적으로 인식되는 아바타"라고 브랜드화합니다.
이 서비스는 특정 이메일에 대한 아바타를 정의할 수 있게 해줍니다. 해당 이메일을 사용해 가입한 모든 제품은 그 아바타를 사용할 수 있습니다.
이렇게 하면 FastComments에 가입하는 사람들의 아바타가 자동으로 설정되어 한 단계가 생략됩니다.

### 그렇다면 변경 사항은?

FastComments는 이제 기본 아바타를 Gravatar에서 가져옵니다. 이 기능을 사용하기 위해 여러분이나 사용자가 별도로 할 일은 없습니다.

기존 사용자가 이미 자신만의 아바타를 정의한 경우에도 걱정하지 마세요. 우리는 사용자 맞춤 아바타를 덮어쓰지 않습니다.
또한, 사용자는 FastComments에서 Gravatar 아바타를 여전히 덮어쓸 수 있습니다.
