# [postlink]Generated Type-Safe Client SDKs Released[/postlink]

{{#unless isPost}}
Όπως αναφέρθηκε στην ανάρτηση για τη μετάβαση σε TypeScript, κυκλοφόρησαν παραγόμενα, τύπου‑ασφαλή client SDKs για δέκα γλώσσες προγραμματισμού.
{{/unless}}

{{#isPost}}

### <i class="circle">!</i> Αυτό το άρθρο περιέχει τεχνική ορολογία

### Τι νέο υπάρχει

Στην [ανάρτηση για τη μετάβαση σε TypeScript](/blog/fastcomments-typescript-migration-completed), αναφέραμε ότι θα κυκλοφορήσουν παραγόμενα client SDKs. Είναι εδώ.

Το FastComments πλέον προσφέρει επίσημα, τύπου‑ασφαλή SDKs για **δέκα γλώσσες**:

- TypeScript / JavaScript (npm)
- Python (GitHub)
- Rust (crates.io)
- Go (Go modules)
- Java (Maven)
- PHP (Composer)
- Ruby (RubyGems)
- Swift (Swift Package Manager)
- C++ (CMake)
- Nim (Nimble)

Κάθε SDK παράγεται από το ίδιο OpenAPI specification που παράγει ο διακομιστής μας. Οι τύποι, οι υπογραφές μεθόδων και τα μοντέλα αιτήσεων/απαντήσεων παραμένουν συγχρονισμένα με το πραγματικό API αυτόματα. Ο μεταγλωττιστής σας εντοπίζει τυπογραφικά λάθη στα ονόματα πεδίων και ελλιπείς παραμέτρους πριν ο κώδικάς σας κάνει οποιοδήποτε αίτημα δικτύου.

### Πώς λειτουργεί

Η μετάβαση σε TypeScript ήταν προαπαιτούμενο για αυτό. Τώρα που ο κώδικας του διακομιστή μας είναι πλήρως τυποποιημένος, χρησιμοποιούμε το [fork μας του TSOA](https://github.com/FastComments/tsoa) για να δημιουργήσουμε ένα OpenAPI 3.0 spec απευθείας από τους ελεγκτές διαδρομών. Αυτό το spec τροφοδοτείται στο [OpenAPI Generator](https://openapi-generator.tech/) για την παραγωγή βιβλιοθηκών client για κάθε γλώσσα.

Όταν το API αλλάζει, το εργαλείο μας εντοπίζει τη διαφορά στο spec, επαναδημιουργεί τα επηρεαζόμενα SDKs, εκτελεί δοκιμές για κάθε γλώσσα και ανοίγει αυτόματα pull requests. Κατασκευάσαμε ένα μικρό εργαλείο διαχείρισης σε Nim που συντονίζει τον κύκλο ενημέρωσης‑δοκιμής‑κυκλοφορίας σε όλα τα δέκα αποθετήρια.

### Τι περιλαμβάνει κάθε SDK

Κάθε SDK παρέχει δύο κλάσεις API:

- **`DefaultApi`**: αυθεντικοποιημένα endpoints που απαιτούν το κλειδί API σας. Χρησιμοποιήστε τα στο server‑side για διαχείριση moderation, χρηστών, analytics και μαζικές λειτουργίες.
- **`PublicApi`**: μη αυθεντικοποιημένα endpoints που είναι ασφαλή για κλήση από browsers και mobile apps. Αυτά καλύπτουν την ανάκτηση σχολίων, την αποστολή, την ψηφοφορία και άλλες λειτουργίες προς το client.

Όλα τα SDKs περιλαμβάνουν επίσης βοηθητικά εργαλεία SSO για ενσωμάτωση με το υπάρχον σύστημα αυθεντικοποίησης. Το TypeScript SDK επιπλέον παρέχει συνδρομές σε πραγματικό‑χρόνο για γεγονότα ζωντανής σχολιαστικής.

### Τεκμηρίωση

Πλήρης τεκμηρίωση API είναι διαθέσιμη στο [docs.fastcomments.com](https://docs.fastcomments.com/guide-api.html). Κάθε αποθετήριο SDK περιλαμβάνει επίσης παραγόμενη τεκμηρίωση που καλύπτει κάθε διαθέσιμη μέθοδο και μοντέλο.

Για ενσωμάτωση SSO, δείτε τον [οδηγό SSO](https://docs.fastcomments.com/guide-sso.html). Όλα τα δέκα SDKs περιλαμβάνουν βοηθητικά SSO χρησιμοποιώντας τις εγγενείς βιβλιοθήκες κρυπτογραφίας τους.

### Συμπερασματικά

Η ύπαρξη ενός πλήρως τυποποιημένου διακομιστή έκανε την παραγωγή ενός αξιόπιστου OpenAPI spec απλή, και από εκεί, η δημιουργία client για δέκα (και κάποια μέρα περισσότερες!) γλώσσες ήταν κυρίως θέμα αυτοματοποίησης
και βελτίωσης των ορισμών τύπων ώστε να είναι καταναλώσιμα, χωρίς να προστίθεται υπερβολική αφαίρεση που θα επιβραδύνει το FastComments!

Όπως συμβαίνει με όλες τις μεγάλες κυκλοφορίες, είμαστε ευχαριστημένοι που μπορέσαμε να αφιερώσουμε χρόνο στη βελτιστοποίηση, τις δοκιμές και τη σωστή κυκλοφορία αυτών των SDKs. Ενημερώστε μας
παρακάτω αν έχετε σχόλια ή αν υπάρχει κάποια γλώσσα που θα θέλατε να προσθέσουμε.

Στην υγειά σας!
