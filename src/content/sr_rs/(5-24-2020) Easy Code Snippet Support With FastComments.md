# [postlink]Лако подржавање кода исечака са FastComments[/postlink]

Неки од наших клијената имају сајтове и блогове везане за софтверски развој. У овим заједницама је уобичајено делити исечке кода. Ево како FastComments ово олакшава.

{{#isPost}}

FastComments омогућава делење кода једноставним налепљивањем у поље за коментаре. Може се комбиновати са осталим текстом и сликама, и не захтева да ручно додајете било какве „code“ ознаке за форматирање. Само налепите!

Ево брзог демо приказа у акцији.

<video src="images/fc-code-snippet-demo.mp4" autoplay controls loop=true alt="Code Snippet Sharing Demo" title="Code Snippet Sharing Demo"></video>

### Утицај на перформансе

Додавање ове функције је повећало величину клијентског виџета за само око 150 бајта, јер се већина функционалности обрађује на серверу. Заправо, ако ово комбинујете са недавно додатим Markdown функцијама, величина виџета је заправо смањена са овим новим функцијама!

### Ствари које треба имати у виду

Ако имате заједницу која интензивно дели код, требало би да размотрите повећање максималне величине коментара како би дељење кода било лакше. Ово се уради преко картице „Customize“ у администраторском контролном панелу.

### Детекција кода

Да бисмо одржали малу величину клијентског виџета, аутоматски ћемо детектовати налепљени код само за C и језике сличне Питону (на пример Java, JavaScript, CSS, C++), који користе „{“ или размаке за контролни ток. Ако често користите језик који се не детектује аутоматски, контактирајте нас.

Да ручно уметнете блок кода, напишите коментар као: ```<code>(defun someLispCode(1, 2, 3))</code>```. Можемо аутоматски детектовати око 150 језика. 

### Миграција постојећих коментара

Ако желите да мигрирате на FastComments и имате много коментара који садрже исечке кода које желите правилно форматирати, <a href="https://fastcomments.com/auth/my-account/help" target="_blank">можемо помоћи</a>.
