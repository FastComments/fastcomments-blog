# [postlink]DKIM конфигурација је сада доступна у корисничком интерфејсу[/postlink]

{{#unless isPost}}
FastComments сада пружа кориснички интерфејс за конфигурисање DKIM‑а, што олакшава побољшање стопе испоруке имејлова без коришћења API‑ја.
{{/unless}}

{{#isPost}}

### Шта је ново

Подешавање DKIM‑а за ваш прилагођени имејл домен је сада лакше. Претходно, конфигурисање DKIM‑а захтевало је директно коришћење
<a href="https://docs.fastcomments.com/guide-api.html#domain-config-structure" target="_blank">Domain Configs API</a>. Сада, можете конфигурисати DKIM директно из FastComments администраторског UI‑а.

### Зашто је DKIM важан

Када прилагодите „From Domain“ за имејлове које FastComments шаље у ваше име, провајдери имејлова морају да потврде да су ти имејлови легитимни. DKIM (DomainKeys Identified Mail) је један од кључних механизама аутентификације који помаже у томе. Без исправне DKIM конфигурације, имејлови послати у име вашег домена имају већи ризик да заврше у спам фасциклама.

### Како да подесите

Идите на страницу <a href="https://fastcomments.com/auth/my-account/configure-domains" target="_blank">My Domains</a> и кликните „Show Advanced“ за домен који желите да конфигуришете. Видећете DKIM подешавања где можете унети име вашег домена, селектор кључа и приватни кључ.

Након чувања, DKIM конфигурација ће се применити на све имејлове послате са тог домена.

### API и даље ради

Ако више волите да управљате DKIM конфигурацијом програмски, <a href="https://docs.fastcomments.com/guide-api.html#domain-config-structure" target="_blank">Domain Configs API</a> и даље функционише као раније.

### У закључку

Надамо се да ће ово олакшати обезбеђивање да ваши корисници примају имејлове које FastComments шаље у ваше име. Јавите нам у наставку ако имате било каквих питања.

Поздрав!
