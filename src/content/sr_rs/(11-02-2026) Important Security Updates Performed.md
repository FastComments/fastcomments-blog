# [postlink]Извршена важна безбедносна ажурирања[/postlink]

{{#unless isPost}}
Поправили смо оперативни систем на свим нашим серверима да поправимо недавну Linux TCP рањивост, и ажурирали Node.js да укључимо његово октобарско безбедносно издање. Није потребна никаква радња са ваше стране.

{{#isPost}}

### Шта је ново

Недавно смо завршили два безбедносна ажурирања у FastComments инфраструктури: ажурирање оперативног система за поправку рањивости у Linux кернеловом TCP коду, и ажурирање Node.js за укључење најновијег безбедносног издања.

### Linux кернел

Сви наши сервери су исправљени и сада раде на кернелу који укључује исправку за
<a href="https://security-tracker.debian.org/tracker/CVE-2026-98432" target="_blank">CVE-2026-98432</a>.

Ово је употреба након ослобађања (use-after-free) у IPv4 TCP коду кернела. Кернел је могао ослободити IP опције придружене вези док је други процесор још увек читао их, на пример док се гради SYNACK одговор током TCP руковања. Исправка чека док ниједан процесор више не чита ту меморију пре него што је ослобађа.

### Node.js

FastComments ради на Node.js, и ажурирали смо на верзију 24.22.1, исправљено издање за 24.x линију из <a href="https://nodejs.org/en/blog/vulnerability/october-2026-security-releases" target="_blank">октобарског 2026 Node.js безбедносног издања</a>.

То издање поправља 10 рањивости у подржаним Node.js верзијама. 8 од њих утиче на 24.x линију, а 4 од њих су оцењене као високе: две у TLS валидацији IP адреса, једна у руковању DNS именима и једна у Brotli декодеру. Такође ажурира уметнуте зависности укључујући OpenSSL, c-ares, Undici и CA сертификат пакет.

### Шта треба да урадите

Ништа. Ова ажурирања су искључиво на нашој страни, тако да ваши виџети, API интеграције и SSO конфигурације не захтевају никакве промене.

### У закључку

Одржавање наше инфраструктуре исправљеном је континуирани део управљања FastComments-ом, и наставићемо да примењујемо таква ажурирања како се објављују. Ако имате било каквих питања, јавите нам их испод.

Поздрав!
