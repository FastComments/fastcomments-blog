# [postlink]Уграђивање коментара на GitHub Pages[/postlink]

{{#unless isPost}}
Желите ли да додате коментаре на статичку страницу, као што је GitHub Pages?
{{/unless}}

{{#isPost}}
#### За програмере
Инсталирање FastComments на веб страницу захтева само уметање малог кода. Ово значи да ради на статичким страницама без икаквих проблема – укључујући бесплатни хостинг GitHub Pages.

#### Демо

Подесили смо пример GitHub странице <a href="https://fastcomments.github.io/fastcomments-demo.github.io/" target="_blank">овде</a>.

<a href="https://github.com/fastcomments/fastcomments-demo.github.io/blob/master/index.html#L29" target="_blank">Овде</a> је линк до места где смо додали кодни исечак за наш тест налог.

#### Подешавање

Мораћете да додате ваш GitHub домен као важећи домен у вашем налогу.
