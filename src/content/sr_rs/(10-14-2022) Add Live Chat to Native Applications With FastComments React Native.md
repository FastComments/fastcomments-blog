### Шта је ново

У FastComments-у смо покренули нови начин за изградњу React Native апликација помоћу FastComments. Претходно, користили сте наш react-native омотач око VanillaJS библиотеке. То је довело до неколико проблема са меморијом и кашњењем због захтевања веб приказа – прегледача у вашој апликацији – само да би се учитала наша библиотека.

Сада смо **потпуно** пренели FastComments на React Native и написали наш сопствени WYSIWYG уређивач како бисмо потпуно елиминисали потребу за веб приказима.

Библиотека подржава различите теме и распореде. На пример, ево теме Erebus која је тамна тема у стилу живог ћаскања:

<div class="text-center">
    <img src="images/skin-erebus.png" alt="Erebus Skin" title="Erebus Skin" />
</div>

Библиотека је доступна [on GitHub at FastComments/fastcomments-react-native-sdk](https://github.com/FastComments/fastcomments-react-native-sdk) као и [on NPM](https://www.npmjs.com/package/fastcomments-react-native-sdk).

### Прилагодљиво

Нова изворна библиотека је дизајнирана да буде прилагодљива као и постојећа веб библиотека.

Можете:

- Прилагодите све ресурсе и иконе које библиотека користи.
- Прилагодите стилизовање сваке компоненте у библиотеци прослеђивањем објекта Styles од врха.
- Прилагодите све преводе.
- Користите једну од унапред дефинисаних или од заједнице развијених тема.
- Користите многе исте конфигурационе опције које веб библиотека подржава.

### Комплетан списак функција

Библиотека подржава многе ствари. Непотпуни списак је:

- [x] Блокирање
- [x] Реакције у ћаскању
- [x] Дете коментари и одговори
- [x] Прилагођени стилови (као типизовани стилски лист)
- [x] Емотикони
- [x] Пријављивање
- [x] Прегледач GIF-ова – са подразумеваним трендовима + могућност претраге. Слике и претрага анонимизоване преко проксија.
- [x] Живо коментарисање
- [x] Одабир медија и отпремање
- [x] Изворни WYSIWYG уређивач са подршком за слике.
- [x] Сервис за обавештења (преузимање непрочитаних обавештења корисника у позадини за слање, итд.)
- [x] Листа обавештења (приказује се када кликнете на звонице). Подржава претплате.
- [x] Пагинација (дугмад)
- [x] Пагинација (бесконачно скроловање)
- [x] Закачињење коментара
- [x] Безбедно, једноставно SSO и анонимно коментарисање.
- [x] Неколико унапред дефинисаних тема.
- [x] Пребацивање приказа/скривања коментара
- [x] Теме
- [x] Индикације активности корисника
- [x] Гласање

### Како функционише

Библиотека је потпуна преписка FastComments клијента у TypeScript-у и React Native-у.

На дуги рок, одржаћемо и VanillaJS библиотеку и react-native библиотеку паралелно, као и све будуће изворне библиотеке које можда развијемо.
