### Шта је ново

Пре 14. новембра 2023. године, направили смо следеће промене у вебхук-овима:

#### Ажурирање вебхука

**Претходно**, ажурирања су садржала најновију верзију коментара. Ако су два корисника брзо гласала за коментар, то је изазивало два вебхука. Међутим, било је могуће да први вебхук догађај садржи најновију верзију, што је резултирало два идентична вебхук догађаја:

1. ` ... { votes: 2 } ...`
2. ` ... { votes: 2 } ...`

**Од 14. новембра** сваки вебхук догађај је идемпотентан и садржи објекат коментара у тренутку промене. У горњем примеру сада ћете добити два догађаја:

1. ` ... { votes: 1 } ...`
2. ` ... { votes: 2 } ...`

#### Брисање вебхука

**Претходно**, вебхукови за брисање су садржали само ID коментара. То је био објекат попут `{ id: string }`.

**Од 14. новембра**, вебхукови за брисање ће садржати цео објекат коментара у тренутку уклањања.
