### Шта је ново

FastComments сада има React Native компоненте које су у потпуној функцијској паритети са нашим VanillaJS виџетом.

Одлучили смо да назовемо библиотеку `fastcomments-react-native`. Репозиторијум на GitHub-у са изворним кодом можете пронаћи <a href="https://github.com/FastComments/fastcomments-react-native" target="_blank">овде</a>.

Репозиторијум такође садржи пример употребе виџета.

Налази се на NPM-у, где га можете пронаћи <a href="https://www.npmjs.com/package/fastcomments-react-native" target="_blank">овде</a>.

### Како функционише

Овај нови компонент функционише тако што је React компонента омотач око постојећег FastComments виџета.

То значи да ако додајемо нове функције у постојеће компоненте или исправљамо грешке, ви ћете одмах имати корист!

### Време развоја

React Native виџети се могу додати у вашу апликацију за само неколико минута, уз минимално време развоја.

### SSO

Све React Native библиотеке подржавају SSO одмах, а процес интеграције SSO је исти као и за Vanilla JS компоненте. Постојећи примери кода за позадински део такође важе.

### Прилагођено стилизовање?

React Native компоненте се могу стилизовати помоћу CSS-а преко корисничког интерфејса за прилагођавање виџета, исто као веб-виџети.
