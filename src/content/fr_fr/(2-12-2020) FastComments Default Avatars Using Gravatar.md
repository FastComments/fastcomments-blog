# [postlink]FastComments Avatars par défaut utilisant Gravatar[/postlink]

### Qu'est-ce qu'un avatar ?

Un avatar est l'icône de profil associée à chaque compte et affichée à côté de chaque commentaire.

### Qu'est-ce que Gravatar ?

<a href="https://gravatar.com/" target="_blank">Gravatar</a> se décrit comme « A Globally Recognized Avatar ». C'est un service qui vous permet de définir un avatar pour une adresse e‑mail donnée. Tous les produits auxquels vous vous inscrivez avec cette adresse e‑mail peuvent alors utiliser cet avatar. Cela supprime une étape pour les personnes qui s'inscrivent à FastComments, car leur avatar est configuré automatiquement.

### Alors, quel est le changement ?

FastComments récupérera désormais les avatars par défaut depuis Gravatar. Vous ou les utilisateurs n'avez rien à faire pour bénéficier de cette fonctionnalité.

Si vos utilisateurs existants ont déjà défini leur propre avatar – pas de souci – nous n'écraserons pas leurs avatars personnalisés.  
De plus, les utilisateurs peuvent toujours remplacer l'avatar Gravatar dans FastComments.
