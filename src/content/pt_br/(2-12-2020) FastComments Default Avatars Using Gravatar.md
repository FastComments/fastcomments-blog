# [postlink]Avatares Padrão do FastComments Usando Gravatar[/postlink]

### O que é um Avatar?

Um avatar é o ícone de perfil associado a cada conta e exibido ao lado de cada comentário.

### O que é o Gravatar?

<a href="https://gravatar.com/" target="_blank">Gravatar</a> se apresenta como "Um Avatar Reconhecido Globalmente".  
É um serviço onde você pode definir um avatar para um determinado e‑mail. Qualquer produto ao qual você se inscreva usando esse e‑mail pode então usar esse avatar. Isso elimina uma etapa para as pessoas que se inscrevem no FastComments, já que seu avatar é configurado automaticamente.

### Então, qual é a mudança?

O FastComments agora buscará avatares padrão do Gravatar. Você ou os usuários não precisam fazer nada para obter esse recurso.

Se seus usuários existentes já definiram seu próprio avatar – não se preocupe – não vamos sobrescrever os avatares personalizados deles. Além disso, os usuários ainda podem sobrescrever o avatar do Gravatar no FastComments.
