# [postlink]FastComments がさらに高速になりました[/postlink]

{{#unless isPost}}
コメントウィジェットの読み込み時にネットワークリクエストを1つ削減し、ロード時間をさらに短縮しました。
{{/unless}}

{{#isPost}}

### <i class="circle">!</i> この文章には技術的な専門用語が含まれています

### 新機能

FastComments が過去約5年間にわたって動作してきた方法は、小さなスクリプトを読み込み、iframe がロードされ、次にスタイルを含むスクリプトが読み込まれ、最後にコメントを描画するために必要なすべてを取得する API へのリクエストを行うという流れです。多く聞こえるかもしれませんが、ほとんどのシステムと比べて非常にコンパクトです！

しかし、現在はさらに1つリクエストが減ります。ウィジェットを配信する iframe のレスポンスにコメントとユーザーが最初に必要とするすべてのデータが含まれるようになったため、最後の API リクエストが不要になりました。

API は、依存しているユーザーのために下位互換性を保つ形で引き続き提供されます。

### 設定は不要

この機能に対する設定はなく、アップグレードすべきバージョンもありません。FastComments を当社のスクリプトで埋め込んでいれば、すでに利用できます。

お客様のページはどちらの場合でも影響を受けません。ウィジェットは引き続き iframe 内でロードされ、コンテンツをブロックしません。以前と全く同じです。

### 適用されないケース

いくつかのパスではこの変更が適用されず、従来通りの動作をします:

- 検索エンジンのクローラは、すでにコメントを iframe ではなくページに直接描画しています
- ユーザーアクティビティフィードとハッシュタグフィルタリングは、別のエンドポイントから取得します
