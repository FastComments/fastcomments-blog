# [postlink]FastComments デフォルトアバターの Gravatar 使用[/postlink]

### アバターとは？

アバターは、すべてのアカウントに関連付けられ、コメントの横に表示されるプロフィールアイコンです。

### Gravatar とは？

<a href="https://gravatar.com/" target="_blank">Gravatar</a> は自らを「世界的に認識されたアバター」と称しています。これは、特定のメールアドレスに対してアバターを設定できるサービスです。そのメールアドレスでサインアップしたすべての製品がそのアバターを使用できます。これにより、FastComments にサインアップする人はアバターが自動的に設定されるため、手間が省けます。

### 変更点は何ですか？

FastComments はデフォルトのアバターを Gravatar から取得するようになりました。この機能を利用するために、あなたやユーザーが何かを行う必要はありません。

既存のユーザーがすでに独自のアバターを設定している場合でも心配はいりません。カスタムアバターを上書きすることはありません。また、ユーザーは FastComments で Gravatar のアバターを上書きすることも可能です。
