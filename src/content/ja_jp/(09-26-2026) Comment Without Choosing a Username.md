# [postlink]ユーザー名を選択せずにコメント[/postlink]

{{#unless isPost}}
FastComments は、各新規訪問者にユニークで中立的なユーザー名を自動で付与できるようになりました。これにより、ユーザーは自分で名前を考える必要がなくなります。また、共有の Default Username が最初に使用した人に「taken」されることもなくなります。
{{/unless}}

{{#isPost}}

### 新機能

サイトにログイン機能がない場合、コメントを残したい訪問者はメールアドレスとユーザー名の 2 つを求められます。メールアドレスは簡単ですが、ユーザー名はユニークで公開される必要があり、今すぐ考えなければなりません。

このリリースではその手順が不要になりました。ウィジェットのカスタマイズで **Generate Usernames Automatically** をオンにすると、各新規訪問者は `BraveOtter4172` のような名前が自動で入力された状態で来訪します。保持しても、上書きしても構いません。いずれにせよ、コメント入力欄に早くたどり着けます。

### 設定方法

<a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">Widget Customization</a> を開き、**Anonymization** セクションで **Generate Usernames Automatically** にチェックを入れます。これ以外に設定する項目はありません。

**Allow Anonymous Comments** の有無に関わらず機能します。すべてのコメント投稿者からメールアドレスを取得したい場合は、匿名コメントをオフにしてください。訪問者はメールアドレスを入力し、ユーザー名は自動で処理されます。メールアドレスが不要な場合は匿名コメントをオンにすれば、コメント本文以外の入力は不要です。

### 訪問者が見る画面

ユーザー名フィールドには生成された名前が事前入力されています。普通の入力欄なので、別の名前にしたい人は自由に書き換えられます。隠された要素や強制される項目はありません。

名前は 2 語と数字の組み合わせで、読みやすく中立的です。`user_83729` のような名前になることはありません。

### すべての名前はユニーク

生成された名前は提供前に既存アカウントと照合され、訪問者のブラウザセッションに予約されます。次の訪問者に同じ名前が提示されることはありません。ログイン中のユーザー、SSO ユーザー、既にコメントしたことのある訪問者には新しい名前は付与されず、既存の名前が保持されます。

以前に使用したメールアドレスで再訪した訪問者は既存アカウントと紐付けられるため、ブラウザをクリアしていても二重の身元が作られることはありません。

### バグ修正 - デフォルトユーザー名が本当に共有されるようになりました

一部の方は **Default Username** に「Anonymous」などの値を設定してこの機能を利用していましたが、そこに問題がありました。ユーザー名はユニークである必要があるため、最初に「Anonymous」とメールアドレスでコメントした訪問者が名前を取得し、別のメールアドレスの次の訪問者には「taken」と表示されていました。

この問題は修正されました。デフォルトユーザー名は個人の ID ではなく、共有表示名として扱われます。デフォルト名を使用したすべての訪問者は裏で個別のアカウントを持ち、表示名は「Anonymous」となります。訪問者が自分で入力したユーザー名は従来通りユニークである必要があります。

両方設定した場合は、生成された名前が優先されます。

この機能は、訪問者が患者であり、たった一度だけフィードバックを残す可能性があるサイトの顧客からの要望で実装されました。メールアドレスとユニークなユーザー名を求めるのは過剰なハードルでした。設定が読者とコメント欄の間に壁を作っている場合は、下のコメントでお知らせください。
