### 新着情報

最近、FastComments のインフラ全体で 2 つのセキュリティアップデートを完了しました。1 つは Linux カーネルの TCP コードにある脆弱性を修正するオペレーティングシステムの更新、もう 1 つは最新のセキュリティリリースを取り込む Node.js の更新です。

### Linux カーネル

すべてのサーバーにパッチが適用され、現在は <a href="https://security-tracker.debian.org/tracker/CVE-2026-98432" target="_blank">CVE-2026-98432</a> の修正が含まれたカーネルが動作しています。

これはカーネルの IPv4 TCP コードにおける use-after-free の脆弱性です。カーネルは、接続に付随する IP オプションを、別の CPU がまだ読み取っている間に解放してしまう可能性があります。例えば、TCP ハンドシェイク中に SYNACK 応答を構築している際です。修正は、そのメモリをまだ読み取っている CPU が存在しなくなるまで待ってから解放するようにしています。

### Node.js

FastComments は Node.js 上で動作しており、<a href="https://nodejs.org/en/blog/vulnerability/october-2026-security-releases" target="_blank">2026年10月の Node.js セキュリティリリース</a>からの 24.x 系のパッチ適用版であるバージョン 24.22.1 に更新しました。

このリリースでは、サポート対象の Node.js バージョン全体で 10 件の脆弱性が修正されています。そのうち 8 件は 24.x 系に影響し、4 件は高リスクと評価されています：TLS における IP アドレスの検証に関する 2 件、DNS 名の処理に関する 1 件、Brotli デコーダに関する 1 件です。また、OpenSSL、c-ares、Undici、CA 証明書バンドルなどのバンドル依存関係も更新されています。

### 必要な対応

何もする必要はありません。これらのアップデートはすべて当社側で行われるため、お客様のウィジェット、API 統合、SSO 設定に変更は不要です。
