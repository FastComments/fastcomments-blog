# [postlink]FastComments 默认头像使用 Gravatar[/postlink]

### 什么是头像？

头像是与每个账户关联的个人资料图标，并显示在每条评论旁边。

### 什么是 Gravatar？

<a href="https://gravatar.com/" target="_blank">Gravatar</a> 将自己定位为 “全球认可的头像”。  
这是一项服务，您可以为指定的电子邮件地址定义头像。使用该电子邮件注册的任何产品随后都可以使用该头像。这为注册 FastComments 的用户省去了一步，因为他们的头像会自动设置。

### 那么有什么变化？

FastComments 现在将从 Gravatar 获取默认头像。您或用户无需进行任何操作即可使用此功能。

如果您现有的用户已经自定义了头像——别担心——我们不会覆盖他们的自定义头像。  
此外，用户仍然可以在 FastComments 中覆盖 Gravatar 头像。
