# [postlink]被封禁用户现在可搜索[/postlink]

{{#unless isPost}}
Banned Users 页面现在有一个搜索行，您可以通过电子邮件、姓名、执行者或导致封禁的评论来查找封禁。
{{/unless}}

{{#isPost}}

### 新功能

在“Moderate Comments”下的 Banned Users 页面现在在表格上方有一个搜索行。直到现在，唯一浏览该列表的方式是页面和每页计数控制，这在只有十几条封禁时还算可以，但当有几千条时就非常痛苦。

共有三个控制项：**Search By** 选择字段，**Match** 选择 Contains 或 Equals，**Value** 是您要查找的内容。

### 您可以搜索的内容

**Search By** 提供五个选项：

- **Any Field** - 一次搜索下面的所有内容
- **Email** - 被封禁的电子邮件地址
- **Name** - 封禁记录中的姓名
- **Banned By** - 发起封禁的版主
- **Banned For Saying** - 导致用户被封禁的评论文本

后四项与表格中同名的列对应，因此下拉菜单的文字与其过滤的内容保持一致。

### 包含 vs 等于

**Contains** 在字段的任何位置查找您的值。**Equals** 则匹配整个字段。

大多数情况下您会使用 Contains。搜索 `bademail.com` 会找到该域名下的所有封禁，包括通配符 `*@bademail.com` 的封禁，因为通配符封禁会保留星号。

Equals 适用于您拥有精确值且不想出现近似匹配的情况。使用 Equals 在 Email 中搜索 `spammer@example.com` 只会返回那一条封禁记录，其他都不会出现。

两者在所有字段上均不区分大小写。这一点比看起来更重要：当封禁是从评论创建时，只有地址的域名部分会被转为小写，因此封禁记录可能真实地存储为 `MixedCase@Example.com`。搜索 `mixedcase@example.com` 能够找到它。

### 两个值得了解的搜索

**Banned For Saying** 会搜索触发封禁的评论文本。如果某个特定短语或链接在传播，您可以一次性查询出所有因该内容被封禁的用户。

**Banned By** 会搜索发起封禁的版主。如果您想审查特定版主的决定，或在为新人培训时想查看他们的操作，只需一次搜索即可。

### 分页和共享均可使用

搜索条件会写入页面 URL，因此在结果中分页时会保持搜索状态，您也可以通过复制 URL 将过滤后的列表发送给其他版主，就像您已经共享的审核链接一样。开始新搜索会返回第一页，**Clear** 则会恢复到完整列表。

### 姓名搜索匹配您看到的内容

封禁记录会保存用户被封禁时的姓名，但表格显示的是他们当前的姓名。这两者并不总是一致，而且如果您通过输入电子邮件地址创建封禁，则该记录根本没有存储姓名。

因此，姓名搜索会解析每条封禁背后的用户，并匹配表格实际显示的姓名。如果某人最初以 “OldHandle” 被封禁，随后改名为 “NewHandle”，两者都能找到他。如果您封禁了一个地址，而表格为其显示了姓名，搜索该姓名也能生效。

### 总结

此功能源于我们观察页面的实际使用方式。封禁会在多年里悄然累积，直到有一天您需要查找特定的封禁，却找不到办法。现在已经可以实现。
