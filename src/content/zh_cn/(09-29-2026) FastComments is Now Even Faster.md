# [postlink]FastComments 现在更快了[/postlink]

{{#unless isPost}}
我们在加载评论小部件时移除了一个网络请求，进一步降低了加载时间。
{{/unless}}

{{#isPost}}

### <i class="circle">!</i> 本文包含技术术语

### 新功能

在过去大约五年里，FastComments 的工作方式是先加载一个小脚本，iframe 加载，然后加载包含样式的脚本，随后向 API 发出请求以获取绘制评论所需的全部数据。虽然听起来步骤很多，但与大多数系统相比，这已经相当紧凑！

然而，现在甚至少了一个请求。提供小部件的 iframe 响应同时携带了评论以及用户最初需要的所有数据，因此最后的 API 请求已被省去。

该 API 仍然保留，以确保依赖它的用户能够向后兼容。

### 无需配置

对此没有任何设置，也没有需要升级的版本。如果你使用我们的脚本嵌入 FastComments，已经默认拥有此功能。

你的页面无论如何都不会受到影响。小部件仍然在 iframe 中加载，且仍然不会阻塞你的内容，完全如之前一样。

### 不适用的情况

有少数路径不使用此优化，它们的行为仍然保持原样：

- 搜索引擎爬虫，它们已经直接将评论渲染到页面中，而不是使用 iframe
- 用户活动源和标签过滤，它们从不同的端点读取

### 结论

我们希望你继续愉快地使用我们的平台，并期待我们的改进能为你带来价值。 :)

祝好!
